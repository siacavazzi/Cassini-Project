### What a Mac thread needs to build sections from this branch
- Inputs the branch requires: `CASSINI_ORIGINALS` (all 125 12-bit volumes; #491's build refuses to start without them) and `CASSINI_CISSCAL_FIX` (the cisscal-fix folder, #493), alongside the usual CASSINI_DATA, KERNELS, SPICE cache, cisscal and a **private copy** of the geometry DB.
- Before building: geometry, then bodies fill (`bootleg_autonav.py geometry` / `bodies`) for #504's relabelled SKY/UNK frames and #525's pointing tags; then `build_data --groups` for the 1997 to 2017 years (#480, #483, #484, #504 and #513 change groups).
- Build each section into its own fresh cache, never the full cache or the live one. The "before" side is main 85d2a2a9 (or cache-full-f9ab1b4 for passes main has not changed since). The 51-item image benchmark (`image_bench.py run --base origin/main --candidate origin/integration/ready-prs-1116`) is the quick first comparison.
- To pin a regression on one PR: rule out the "no" rows below, then build the pass at the merge commit just before and just after the suspect row (`git bisect --first-parent` works on this branch).
How to read this:
- One row per merge on the branch, in merge order. Each PR is its own merge commit ("Merge PR #N: ..."), so `git bisect --first-parent` over `main..integration/ready-prs-1116` lands on exactly one PR.
- **Pixels**: `no` = this PR cannot change a stored picture, so rule it out at once. `YES` = it changes pictures (what a viewer would notice is in the next column). `new files only` = it adds pictures without changing any made before.
- **Versions** are the numbers the PR ends up with on this branch after renumbering in merge order (they differ from the numbers in the PR itself, because many PRs claimed the same numbers). An obs (mosaic/movie) bump renames every pass folder, so a section built from the branch remakes every pass in it whatever the row says; the row says where the visible change is.
- **Evidence**: before/after pictures committed with the PR (`evidence/...` on the branch), or the PR page.
- Base: main 85d2a2a9 (the full cache was built at f9ab1b4; main since then adds #475, #477, #478, #485 and #525).
